Strong in-process 原則卡:AK~AN 都照它拆

Problem:只為達到行數就搬函式，會把一個 deep module 拆成幾個 interface 幾乎等於 implementation 的 shallow module；而測試直接 patch 模組屬性，函式一搬進子模組，patch 就再也蓋不到子模組內部的呼叫，測試安靜地失效。

Solution:沿著 CONTEXT 已有名字的 seam 切，大檔改成同名 package，__init__ 只轉發原本的公開名字 —— 呼叫端零改動,「舊檔只負責引用或轉發」字面成立。依賴改由參數注入(X、AG、K)先做，才拆 patch 最多的檔。

  • 呼叫端零改動
  • interface 不變、檔案變小
  • 子模組可各自測
  • patch 私有名的測試先清掉
與 ADR 不衝突。ADR-0001(地址庫擁有台灣文字正規化)、0011、0012 都是「誰擁有」的決定，package 化保留擁有者。
