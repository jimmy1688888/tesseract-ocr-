### 九項決策共識(架構改了也照樣成立)

1. Gemini **只做離線比對**,不進 pipeline、不進證據模型、**不碰許可證**
2. 真值來自 Sheets **P 欄「已核」**由人簽的列
3. 走 **Vertex AI** 復用現有身分,不開 API key、不走免費層(個資不進訓練)
4. 模型 **Flash-Lite**;判錯的格再單獨重跑一次 Pro
5. **雙模式**診斷分解:文字模式測解析的錯、圖片模式測讀值的錯
6. 輸出要 **5 欄值 + 每欄來源依據原文**,不要自評信心分數
7. 等值判準**分欄不同**(姓名逐字嚴格不折疊、地址過 `fold_variants`)
8. 驗收 = 準確率提升 **且** 零新增安靜錯值(第二條是硬條件)
9. 「安靜錯值」立為 CONTEXT.md 術語

三個**明確否決**的選項(別再提):不讓 Gemini 讀許可證(4 碼無檢查碼、幻覺與真值同形、
且該欄已有兩條證據管道);不用 `upload_log.csv` 當真值(它只記 B 欄,而且**從未被寫出過**);
不走 AI Studio 免費層(影像會被用於改善 Google 產品)。
